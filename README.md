# TheDrawnMotion — Collector's Run

Tarayıcıda çalışan konsol tarzı sürüş oyunu prototipi.

## İçerik

- Overland Silverado ve CLK 55 AMG Cabriolet
- Neon City Circuit, Red Rock Expedition ve Alpine Ink Run haritaları
- Kayıp çizim sayfalarını toplama görevi
- Klavye, dokunmatik ekran ve Gamepad API desteği
- Süre, hız, rota ilerlemesi, derecelendirme ve en iyi tur kaydı

## Kontroller

- `W` / `↑`: Gaz
- `S` / `↓`: Fren
- `A` / `←`: Sol
- `D` / `→`: Sağ
- `Esc`: Duraklat

Bu depo TheDrawnMotion oyun konsepti için hazırlanmış oynanabilir bir prototiptir.
